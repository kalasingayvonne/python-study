# Python Study 🐍

A collection of Python exercises and mini-scripts written while studying core language fundamentals as part of the Software Engineering with AI course at Techcamp. Each file focuses on practicing a specific concept before applying it in larger projects like [MyDuka](https://github.com/kalasingayvonne/myduka) and [findmybean](https://github.com/kalasingayvonne/findmybean).

## Topics Covered

- **Basics** — variables, data types (int, float, string), operators, taking user input
- **Control Flow** — conditional statements, loops, nested logic
- **Data Structures** — lists, tuples, dictionaries, sets
- **Functions** — writing and calling reusable functions
- **Strings** — string manipulation and built-in string methods
- **Practice Exercises** — small applied problems (e.g. area of a circle) and numbered coding tasks assigned during the course

## Repository Structure

```
python-study/
├── basics/              # variables, data types, operators, input
├── control_flow/        # conditionals, loops, nested logic
├── data_structures/     # lists, tuples, dictionaries, sets
├── functions/           # function definitions and usage
├── strings/             # string operations and methods
└── exercises/           # applied practice tasks
```
